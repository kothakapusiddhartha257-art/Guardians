## 🚀 How to Install / Reload in 15 Seconds

1. Open **Google Chrome**, **Microsoft Edge**, or **Brave Browser**.
2. Navigate to `chrome://extensions` (or `edge://extensions`).
3. Toggle on **"Developer mode"** in the top-right corner.
4. Click **"Load unpacked"** (or click the 🔄 reload icon if already loaded).
5. Select the **`extension`** folder:
   ```
   C:\Users\mukes\OneDrive\Desktop\MTZ!\extension
   ```
6. The **TRACEGUARD AI** shield icon `🛡️` is now active!
