# Phishing Shield - Browser Extension

A real-time, privacy-first browser extension for scanning emails, web pages, and URLs for phishing threats. Built using **Manifest V3** for Google Chrome, Microsoft Edge, Brave, and other Chromium browsers.

---

## 🚀 How to Install & Run in Your Browser

### In Google Chrome:
1. Open Google Chrome.
2. In the address bar, type `chrome://extensions` and press **Enter**.
3. In the top-right corner, toggle **Developer mode** to **ON**.
4. Click the **Load unpacked** button in the top-left.
5. Select the `PhishingScanner-extension` folder:
   ```
   c:\Users\mukes\OneDrive\Desktop\MT!\PhishingScanner-extension
   ```
6. Click **Select Folder**. The **Phishing Shield** extension is now installed!
7. (Recommended) Click the puzzle piece icon (Extensions) in Chrome's top toolbar and **pin** 📌 `Phishing Shield` for easy access.

---

### In Microsoft Edge:
1. Open Microsoft Edge.
2. In the address bar, type `edge://extensions` and press **Enter**.
3. In the left sidebar, turn on **Developer mode**.
4. Click **Load unpacked**.
5. Select the `PhishingScanner-extension` folder:
   ```
   c:\Users\mukes\OneDrive\Desktop\MT!\PhishingScanner-extension
   ```

---

### In Brave Browser:
1. Open Brave.
2. In the address bar, type `brave://extensions` and press **Enter**.
3. Enable **Developer mode** (top-right).
4. Click **Load unpacked** and select the `PhishingScanner-extension` folder.

## 🛡️ How to Use the Extension

### 1. Webmail Auto-Scan (Gmail / Outlook)
- Open any email in **Gmail** (`mail.google.com`) or **Outlook Web** (`outlook.live.com`).
- Click the **Phishing Shield** icon in your browser toolbar.
- Click **Scan Open Email**. The extension will automatically read the sender, subject, body, and links, and give you an immediate Risk Score (0–100%) and Threat Breakdown.

### 2. Manual / Custom Text Scan
- Click the extension icon and select the **✍️ Manual Check** tab.
- Paste any email sender, subject, or message body.
- Click **Analyze Email** (or click **Load Sample** to see a live phishing detection simulation).

### 3. URL Safety Inspection
- Switch to the **🔗 URL Check** tab.
- Paste any suspicious link (e.g. `http://bit.ly/...` or domain) to check for URL shorteners, fake subdomains, or credential harvesting keywords.

### 4. Right-Click Context Menu
- Highlight any text or link on any website.
- Right-click and choose **🛡️ Scan Selection for Phishing** or **🔍 Inspect Link with Phishing Shield**.
